# Azazel's Alchemy Table 1.1.0

Полностью пересобранный GitHub-проект мода для **Minecraft 1.21.1 + Fabric**.

## В этой сборке

- точная модель из `art/Potion_table.bbmodel`;
- 22 элемента модели;
- 12 оригинальных текстур из самого `.bbmodel`;
- исправленный block model JSON;
- серый GUI 176×166;
- фиксированные подписи без наложения текста;
- координаты слотов подогнаны под GUI;
- 4 слота алхимического стола;
- сохранение содержимого;
- смешивание двух обычных зелий;
- итоговое зелье с обоими эффектами;
- выпадение предметов при разрушении;
- GitHub Actions для сборки JAR.

## Проверка

1. Установить Fabric 1.21.1.
2. Положить Fabric API и новый JAR 1.1.0 в `mods`.
3. В творческом режиме:
   `/give @s azazels-alchemy-table:alchemy_table`
4. Поставить стол.
5. Открыть ПКМ.
6. Положить два обычных зелья, Glass Bottle и Blaze Powder.

## Сборка на GitHub

После загрузки проекта GitHub Actions автоматически выполняет Gradle build.
Готовый JAR скачивается из Artifacts.
